## SearchDog for executive search firms

SearchDog is a desktop AI sourcing researcher for recruitment agencies. Give it a job brief and approve the search strategy. It then finds and reviews profiles through your team’s authorized Liepin or LinkedIn account and returns a shortlist. For each person, the recruiter can check what in the CV supports the match, what to ask next, and whom to approach. [See the sourcing workflow](https://searchdog.cc/en/ai-sourcing-agent.html)

The official download page lists current Windows and Mac installers and their system requirements. The releases in this GitHub repository document earlier versions. [Download SearchDog](https://searchdog.cc/en/download.html)

Desktop 1.6.7, released on 20 November 2026, accepts a Word or PDF job brief in a Liepin sourcing conversation and uses it to build several search strategies. The same page documents the changes to browser extension 2.0.2. [Read the dated release notes](https://searchdog.cc/en/updates.html#desktop-1-6-7)

- Watch a LinkedIn search from the brief to profile review. The recording is in Mandarin and the page includes an English guide. [LinkedIn walkthrough](https://searchdog.cc/en/linkedin-sourcing-demo.html)
- Inspect an Excel shortlist with CV evidence and follow-up questions for two fictional candidates. [Download the sample shortlist](https://searchdog.cc/support/sourcing-shortlist-en.html#export)
- Try a client submission format with a blank Word form, a manually completed example and a second fictional CV. [Download the Word examples](https://searchdog.cc/support/word-recommendation-report-en.html#samples)
- Use an open role for a product demonstration. [Contact SearchDog](https://searchdog.cc/en/contact.html)
